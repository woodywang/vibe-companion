🚗 Vibe Companion · 速度表悬浮动画预览

风格：经典黑底白针 · 老式汽车速度表。圆形表盘 + 白色刻度/数字 + 弹性指针 + 红线区 + 数字显示窗。纯 SwiftUI 绘制方案。

2 · 弹性指针 + 速率映射

拖动滑块改变 token 速率，观察指针带过冲回摆地缓动到目标角度（弹簧物理）。指针角度 = 速率映射。

交互演示
拖动滑块 → 指针弹性转动

0 tok/min → 0°
映射值
0 tok/min最左（-135°）
8000 tok/min正上（0°）= 1.0×
16000 tok/min最右（+135°）红线区
弹性spring：过冲 + 阻尼回摆
SwiftUI 用 .rotationEffect + .animation(.spring(response:dampingFraction:)) 实现弹性，无需关键帧。

3 · 状态展示

idle（指针回 0）、正常骑行、高速（进入红线区）三态。纯 SwiftUI 下无需 markers，指针角度即状态。
