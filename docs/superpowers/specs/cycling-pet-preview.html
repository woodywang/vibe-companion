状态切换过渡：需要你决策

方案甲 · marker 瞬切
idle→pedal 直接切换播放段
实现简单，切换瞬间有"跳帧"感
方案乙 · 平滑过渡段
idle→pedal 间加 ~10 帧起步过渡
更自然，需多做过渡帧段

两者都用同一 Lottie 文件 markers。方案甲（MVP 推荐）：状态变化时 lottie 切换播放段，瞬切。 方案乙：额外制作 idle→pedal / pedal→idle 的过渡帧段，切换时先播过渡段再进循环。
